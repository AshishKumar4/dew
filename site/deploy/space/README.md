[dewml/hybrid-dit-176m](https://huggingface.co/dewml/hybrid-dit-176m) is a 176M-parameter
text-to-image model at 256×256, trained with [Dew](https://dewml.dev). This Space shows the
live sampler from [dewml.dev/sample](https://dewml.dev/sample/): edit the prompt, the seed, the
steps or the solver and press Run. The cell runs on a shared 4-vCPU host that already holds the
model.

The source of this Space is `site/deploy/space` in [Dew's repository](https://github.com/AshishKumar4/dew).
